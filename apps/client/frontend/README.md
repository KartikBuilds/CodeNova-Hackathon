# CodeNova Frontend

React + Vite SPA for CodeNova learning platform.

## Development

```bash
npm install
npm run dev
```

API connects to http://localhost:5000 (or set VITE_API_BASE_URL in .env.local).

## Build

```bash
npm run build
```

Outputs to `dist/`.

## Environment

See `.env.local.example` for configuration.
